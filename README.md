# Tienda online: API REST contenerizada

**Autor:** Sergio Domínguez

## Descripción
Aplicación Python que implementa una tienda online. Las clases del dominio
(`Producto`, `Usuario`, `Pedido`) y la capa de servicios (`TiendaService`) vienen
de la Práctica 1.3, y la Práctica 2 las expone como una API REST con FastAPI para
gestionar usuarios, productos y pedidos.

Este repositorio se usa en las prácticas 3.1 (control de versiones con Git y GitHub)
y 3.2 (contenerización con Docker).
